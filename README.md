# AIS Controller Simulator

This project is a Java Swing application that reproduces an AIS controller.

## Layout

```text
src/main/java/ais/
  app/          application entry point
  codec/        AIS encoder/decoder
  controller/   controller classes
  model/        data and state models
  network/      UDP communication
  util/         utility classes
  view/         Swing views
out/            compiled classes, generated by build.ps1
```

## Build

```powershell
.\build.ps1
```

## Run

```powershell
java -cp out ais.app.AISMain2
```

Generated `.class` files and the `out/` directory are ignored by Git.
